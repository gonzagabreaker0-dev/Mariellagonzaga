# Pexo Agent

Generate AI videos using multiple video models.

Category: Color, Audio & AI Video Generation (skill #24)

## Workflow

1. Clarify the concept, duration, and style
2. Write a model-appropriate prompt per shot
3. Pick a video model per shot based on strengths and budget
4. Generate, compare, and iterate
5. Stitch the best takes together

## Notes

- Confirm inputs (source files, brand assets, target platform) before starting.
- Prefer ffmpeg / Remotion / Playwright where available; check they are installed first.
- Keep intermediate and output files in a dedicated project folder.
