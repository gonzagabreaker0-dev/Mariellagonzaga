# B-Roll Overlay

Add relevant B-roll to talking-head videos.

Category: Shorts & Visual Assets (skill #15)

## Workflow

1. Transcribe and mark moments that benefit from visuals
2. Source or generate matching B-roll
3. Overlay with cutaways while keeping the original audio continuous
4. Match pacing to speech; avoid covering key expressions
5. Render and review

## Notes

- Confirm inputs (source files, brand assets, target platform) before starting.
- Prefer ffmpeg / Remotion / Playwright where available; check they are installed first.
- Keep intermediate and output files in a dedicated project folder.
