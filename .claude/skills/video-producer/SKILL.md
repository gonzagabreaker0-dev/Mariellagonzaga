# Video Producer

Create product demos with scripts, screen recordings, and voiceovers.

Category: Complete Video Workflows (skill #27)

## Workflow

1. Write the demo script and shot list
2. Record the screen following the script (Playwright for web apps)
3. Generate or record the voiceover
4. Edit: sync audio, add zooms/callouts, trim dead time
5. Render and QA the final demo

## Notes

- Confirm inputs (source files, brand assets, target platform) before starting.
- Prefer ffmpeg / Remotion / Playwright where available; check they are installed first.
- Keep intermediate and output files in a dedicated project folder.
