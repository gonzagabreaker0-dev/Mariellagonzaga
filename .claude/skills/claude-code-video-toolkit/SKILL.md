# Claude Code Video Toolkit

Handle scripting, audio, editing, and rendering in one workflow.

Category: Complete Video Workflows (skill #28)

## Workflow

1. Script: outline and write the narration
2. Audio: voiceover and music
3. Edit: assemble clips, captions, and graphics
4. Render: export in the required formats
5. Keep every stage's assets in an organized project folder

## Notes

- Confirm inputs (source files, brand assets, target platform) before starting.
- Prefer ffmpeg / Remotion / Playwright where available; check they are installed first.
- Keep intermediate and output files in a dedicated project folder.
