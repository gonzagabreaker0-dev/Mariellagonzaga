# Claude Shorts

Find the best moments and turn them into engaging clips.

Category: Shorts & Visual Assets (skill #13)

## Workflow

1. Read the transcript and score moments for hook, emotion, and payoff
2. Shortlist the top moments with timestamps and reasoning
3. Cut and polish each clip
4. Write a hook title and caption for each
5. Present results ranked by expected engagement

## Notes

- Confirm inputs (source files, brand assets, target platform) before starting.
- Prefer ffmpeg / Remotion / Playwright where available; check they are installed first.
- Keep intermediate and output files in a dedicated project folder.
