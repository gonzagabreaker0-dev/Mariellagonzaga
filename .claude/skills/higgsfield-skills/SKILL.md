# Higgsfield Skills

Create AI UGC ads, faceless videos, and character-based content.

Category: Color, Audio & AI Video Generation (skill #25)

## Workflow

1. Define product, audience, and ad angle
2. Write the UGC-style script and shot list
3. Generate the character/scenes with Higgsfield (API key required)
4. Add voiceover, captions, and CTA
5. Deliver variants for A/B testing

## Notes

- Confirm inputs (source files, brand assets, target platform) before starting.
- Prefer ffmpeg / Remotion / Playwright where available; check they are installed first.
- Keep intermediate and output files in a dedicated project folder.
