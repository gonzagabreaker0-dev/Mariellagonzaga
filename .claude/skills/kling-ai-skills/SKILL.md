# Kling AI Skills

Generate AI videos or build better text-to-video prompts.

Category: Color, Audio & AI Video Generation (skill #26)

## Workflow

1. Clarify subject, action, camera movement, and style
2. Write a structured prompt: subject, motion, camera, lighting, mood
3. Generate with Kling (API key required) or output the prompt only
4. Iterate on artifacts and motion issues
5. Return the final prompt and settings used

## Notes

- Confirm inputs (source files, brand assets, target platform) before starting.
- Prefer ffmpeg / Remotion / Playwright where available; check they are installed first.
- Keep intermediate and output files in a dedicated project folder.
