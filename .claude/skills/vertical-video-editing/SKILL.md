# Vertical Video Editing

Create Reels with animated captions, transitions, and effects.

Category: Animations & Motion Graphics (skill #9)

## Workflow

1. Reframe source footage to 9:16
2. Transcribe and add animated word-level captions
3. Add transitions, zooms, and effects at beat points
4. Keep safe zones clear of platform UI
5. Export at 1080x1920

## Notes

- Confirm inputs (source files, brand assets, target platform) before starting.
- Prefer ffmpeg / Remotion / Playwright where available; check they are installed first.
- Keep intermediate and output files in a dedicated project folder.
