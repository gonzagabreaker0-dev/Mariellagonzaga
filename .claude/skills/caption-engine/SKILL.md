# Caption Engine

Create hooks and captions from video transcripts.

Category: Video Analysis & Captions (skill #21)

## Workflow

1. Read the transcript and identify the core takeaway
2. Write 3-5 hook options (first 3 seconds)
3. Write platform-appropriate captions and hashtags
4. Match the creator's voice
5. Present options and recommend one

## Notes

- Confirm inputs (source files, brand assets, target platform) before starting.
- Prefer ffmpeg / Remotion / Playwright where available; check they are installed first.
- Keep intermediate and output files in a dedicated project folder.
