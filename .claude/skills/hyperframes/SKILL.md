# HyperFrames

Create animated titles, explainers, and product videos.

Category: Animations & Motion Graphics (skill #6)

## Workflow

1. Clarify the goal, audience, duration, and aspect ratio
2. Draft a scene-by-scene storyboard with on-screen text
3. Build the animated frames/scenes in code (HTML/CSS/JS or the project's framework)
4. Render a preview and refine timing and easing
5. Export the final video

## Notes

- Confirm inputs (source files, brand assets, target platform) before starting.
- Prefer ffmpeg / Remotion / Playwright where available; check they are installed first.
- Keep intermediate and output files in a dedicated project folder.
