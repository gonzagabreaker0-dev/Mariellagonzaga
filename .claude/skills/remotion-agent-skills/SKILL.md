# Remotion Agent Skills

Build custom animated videos using code.

Category: Animations & Motion Graphics (skill #10)

## Workflow

1. Define the video as React components (compositions, sequences)
2. Drive animation from the frame number, not timers
3. Parameterize content via props so videos can be generated in bulk
4. Test in Remotion Studio
5. Render to MP4 and verify

## Notes

- Confirm inputs (source files, brand assets, target platform) before starting.
- Prefer ffmpeg / Remotion / Playwright where available; check they are installed first.
- Keep intermediate and output files in a dedicated project folder.
