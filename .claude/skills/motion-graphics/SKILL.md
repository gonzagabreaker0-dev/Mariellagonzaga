# Motion Graphics

Create animated B-roll, transitions, and branded graphics.

Category: Shorts & Visual Assets (skill #14)

## Workflow

1. Gather brand colors, logo, and fonts
2. Design lower-thirds, transitions, and animated B-roll
3. Keep a consistent motion language (easing, durations)
4. Export with alpha/transparency where needed
5. Provide reusable templates

## Notes

- Confirm inputs (source files, brand assets, target platform) before starting.
- Prefer ffmpeg / Remotion / Playwright where available; check they are installed first.
- Keep intermediate and output files in a dedicated project folder.
