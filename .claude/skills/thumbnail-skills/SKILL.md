# Thumbnail Skills

Create branded YouTube thumbnails and video covers.

Category: Shorts & Visual Assets (skill #16)

## Workflow

1. Pick the single idea/emotion the thumbnail must convey
2. Use a high-contrast subject, 3-5 words max of text, brand palette
3. Produce 2-3 variants at 1280x720
4. Check legibility at small sizes
5. Export as JPG/PNG under 2MB

## Notes

- Confirm inputs (source files, brand assets, target platform) before starting.
- Prefer ffmpeg / Remotion / Playwright where available; check they are installed first.
- Keep intermediate and output files in a dedicated project folder.
