# Remotion Motion Graphics

Make smooth text animations, intros, and outros.

Category: Animations & Motion Graphics (skill #7)

## Workflow

1. Confirm the text, brand colors, fonts, and duration
2. Scaffold or reuse a Remotion composition
3. Animate with spring()/interpolate() for smooth easing
4. Preview with the Remotion Studio and tune timing
5. Render with `npx remotion render`

## Notes

- Confirm inputs (source files, brand assets, target platform) before starting.
- Prefer ffmpeg / Remotion / Playwright where available; check they are installed first.
- Keep intermediate and output files in a dedicated project folder.
