# Clipify

Turn long videos into multiple short clips automatically.

Category: Shorts & Visual Assets (skill #11)

## Workflow

1. Transcribe the long video
2. Detect topic boundaries and high-interest segments
3. Cut clips of 15-60s with clean start/end points
4. Add captions and a hook
5. Export each clip with a descriptive filename

## Notes

- Confirm inputs (source files, brand assets, target platform) before starting.
- Prefer ffmpeg / Remotion / Playwright where available; check they are installed first.
- Keep intermediate and output files in a dedicated project folder.
