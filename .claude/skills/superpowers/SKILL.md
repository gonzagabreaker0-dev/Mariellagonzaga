# Superpowers

Help Claude follow the right skills and workflows for video production.

Category: Complete Video Workflows (skill #29)

## Workflow

1. At the start of a video task, list the available video skills in this repo
2. Choose the skill(s) that match the request and state why
3. Follow each skill's steps in order; don't skip QA
4. Brainstorm and plan before building; verify before claiming done
5. Hand off between skills with clear intermediate files

## Notes

- Confirm inputs (source files, brand assets, target platform) before starting.
- Prefer ffmpeg / Remotion / Playwright where available; check they are installed first.
- Keep intermediate and output files in a dedicated project folder.
